# Xbox screenshots

Captured on 2026-10-19 from the running original Xbox build through the ESP
HDMI KVM from the [ESP-KVM Xbox fork](https://github.com/ZacharyLeahan/espkvm-xbox).
These are unedited JPEG frames, not mockups or emulator captures.
Both use the Modern theme. The optional FPS overlay is disabled in the gameplay
image and enabled in the controls image.
The KVM-delivered frames are 720×480 pixels.

- `xbox-gameplay.jpg`: a 1v1 match with controller 1 jumping near the net
  against a level-3 AI opponent; the ball and score are visible.
- `xbox-controls.jpg`: the Xbox Controls screen showing button mappings,
  physical controller ports 1–4, pause/resume, and Exit / System navigation.
